# Panier Protéiné

Appli gratuite pour progresser en street workout avec un budget étudiant :
plan de repas protéinés (avec le CROUS), liste de courses Lidl et Leclerc,
séances qui s'adaptent à tes résultats, arbre de figures, suivi du poids, du sommeil et de l'hydratation,
et un coach qui répond à tes questions.

## Installer sur ton téléphone
1. Ouvre l'adresse GitHub Pages du dépôt dans Chrome (Android) ou Safari (iPhone).
2. Android : menu ⋮ → « Installer l'application ». iPhone : bouton Partager → « Sur l'écran d'accueil ».

Tes données restent sur ton téléphone. Pense à télécharger une sauvegarde depuis l'onglet Profil.

## Coach IA (optionnel)
Coach → Réglages : colle une clé Google Gemini (offre gratuite sur aistudio.google.com)
ou Anthropic (console.anthropic.com). La clé reste sur ton téléphone.

Données nutritionnelles : table Ciqual (ANSES) et Open Food Facts. Prix : estimations, à corriger avec tes relevés.
